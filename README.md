# photo-editing-app
A CapCut-inspired photo editor web app with filters, adjustment sliders, text overlays, stickers, and export.

## Features
- Upload any image
- Brightness, contrast, saturation, blur, rotation controls
- Preset effects: Original, Warm, Vintage, Cinematic, Cool, Mono
- Add text overlay with color and font-size settings
- Add sticker overlays
- Reset and download edited image

## Run locally
Open `index.html` in a browser, or from the project folder run:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Files
- `index.html` — app layout
- `styles.css` — interface styling
- `script.js` — editing logic
